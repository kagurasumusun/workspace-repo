# Autonomous workspace state

These files are durable execution state for long-running agent work.

- TASK.md — current task contract.
- PLAN.md — complete deliverable/milestone ledger.
- STATUS.md — current execution position.
- DECISIONS.md — important decisions and rejected alternatives.
- EVIDENCE.md — evidence index and gaps.
- IMPLEMENT.md — execution runbook.
- COMPLETION.md — completion gate.

Agents must read these files before substantive work and update them during execution.

Do not delete incomplete work to make the gate pass.
