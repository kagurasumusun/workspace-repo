# Autonomous Execution Runbook

1. Read the durable state.
2. Establish or refresh TASK.md.
3. Inventory the requested surface.
4. Build a complete PLAN.md deliverable ledger.
5. Route to Skills.
6. Research required unknowns.
7. Implement one milestone.
8. Verify it.
9. Update PLAN/STATUS/DECISIONS/EVIDENCE.
10. Continue to the next incomplete milestone.
11. Run coverage audit.
12. Run completion gate.
13. Only then report completion.

Never use "I created one representative item" as a completion condition.

When a milestone fails:
- record the failure;
- classify it;
- repair or choose another strategy;
- re-run verification;
- only then advance.

When blocked:
- prove the blocker;
- record alternatives attempted;
- record the exact missing external dependency;
- continue all independent work before asking the user.
