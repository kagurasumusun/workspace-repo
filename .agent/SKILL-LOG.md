## Rule

For every substantive task, record the selected Skill before execution and mark Loaded SKILL.md only after its instructions were actually read.

A Skill that was merely mentioned, matched by keyword, or listed by the router is not considered used.

For a broad unknown WinCE task, the expected first specialist Skill is wince-surface-discovery. Subsequent Skills are added as their prerequisites become satisfied.

A Skill may record abstain when it is not applicable. Abstain returns control to the parent task and is not completion.
